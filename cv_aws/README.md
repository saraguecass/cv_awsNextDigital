# CV estático desplegado en AWS CloudFront

Este proyecto consiste en una página web estática tipo currículum desarrollada con CloudFront de AWS.

## Servicios utilizados

- Amazon S3 para almacenar los archivos estáticos de la web.
- Amazon CloudFront para distribuir el contenido desde el edge de AWS.
- GitHub para almacenar el código fuente.

## Archivos principales

- index.html: estructura principal de la web.
- style.css: estilos visuales de la página.
